FAQs

Common questions regarding Edge AI, FPGA architecture & embedded engineering

An Edge-AI accelerator (such as an FPGA CNN engine or dedicated NPU like the Arm Ethos-U55) executes neural network tensor computations directly on localized hardware rather than streaming data to remote cloud servers. This drastically minimizes latency, cuts power consumption, guarantees deterministic timing, and preserves data privacy by never letting raw camera or sensor feeds leave the device.

μT-Kernel 3.0 is a standardized real-time operating system (RTOS) developed under the TRON Project. In high-speed vision systems, tasks like camera DMA frame capture, NPU weight processing, and LCD frame buffer rendering must run concurrently with strict deterministic deadlines. An RTOS provides prioritized preemption, semaphore synchronization, and predictable latency that bare-metal code cannot cleanly manage.

In software, encryption consumes significant CPU clock cycles and suffers from variable execution time depending on cache hits and OS interrupts. In contrast, implementing an 8-bit Substitution-Permutation Network (SPN) in Verilog RTL transforms rounds of substitution, permutation, and key mixing into pure combinational logic and registers, executing in constant clock cycles with zero host CPU load.

Floating-point 32-bit models require excessive memory bandwidth and silicon area. Using Post-Training Quantization (PTQ) or Quantization-Aware Training (QAT), weights and activations are mapped to 8-bit integers (INT8) with minimal accuracy degradation. Dedicated NPU MAC (Multiply-Accumulate) units process INT8 vectors at 4x higher throughput and significantly reduced milliwatt budgets.
