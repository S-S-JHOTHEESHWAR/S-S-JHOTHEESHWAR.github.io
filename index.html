FAQs

Common questions about Edge AI & embedded engineering

An Edge-AI accelerator (such as an FPGA CNN engine or dedicated NPU like the Arm Ethos-U55) executes neural network tensor computations directly on localized hardware rather than streaming data to the cloud. This minimizes latency, cuts power consumption, guarantees deterministic timing, and preserves data privacy.

μT-Kernel 3.0 is a standardized real-time operating system from the TRON Project. In high-speed vision systems, tasks like camera DMA capture, NPU inference, and LCD rendering must run concurrently with strict deterministic deadlines. An RTOS provides prioritized preemption, semaphore synchronization, and predictable latency that bare-metal code cannot cleanly manage.

Software encryption consumes significant CPU cycles and suffers from variable execution time. Implementing an 8-bit Substitution-Permutation Network in Verilog RTL transforms the cipher rounds into pure combinational logic, executing in constant clock cycles with zero host CPU load — ideal for real-time sensor data streams.

Floating-point 32-bit models require excessive memory bandwidth and silicon area. Using Post-Training Quantization (PTQ) or Quantization-Aware Training (QAT), weights and activations are mapped to 8-bit integers with minimal accuracy degradation. Dedicated NPU MAC units process INT8 vectors at 4x higher throughput and significantly reduced milliwatt budgets.
